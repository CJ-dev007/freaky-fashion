# Freaky Fashion 

Freaky Fashion är mitt första större projekt inom webbutveckling och skapades som en del av min utbildning till frontendutvecklare på EC Utbildning.

Projektet är en fiktiv e-handelswebbplats för en klädbutik. Här fick jag arbeta med både frontend och backend och prova på hur en webbapplikation kan kopplas till en databas.

## Projektets syfte

Syftet med projektet var att omsätta våra kunskaper i praktiken och bygga en fungerande e-handelswebbplats från grunden.

Jag fick bland annat arbeta med:

* Semantisk HTML
* CSS och responsiv design
* Flexbox och CSS Grid
* JavaScript och interaktivitet
* Node.js och Express
* SQLite3 och databashantering
* Git och GitHub

## Tekniker & verktyg

* **HTML5** – struktur och innehåll
* **CSS3** – styling, layout och responsiv design
* **JavaScript** – interaktivitet och funktionalitet
* **Node.js** – backend och servermiljö
* **Express** – ramverk för backend och hantering av routes
* **SQLite3** – lokal databas för lagring och hantering av data
* **Git & GitHub** – versionshantering

## Funktioner

Projektet innehåller bland annat:

* Startsida för den fiktiva klädbutiken
* Produktvisning och produktinformation
* Navigering mellan olika delar av webbplatsen
* Varukorg och checkout
* Responsiv layout för olika skärmstorlekar
* Dynamisk hantering av produktdata
* Kommunikation mellan frontend, backend och databas

## Backend & databas

I projektet använde jag **Node.js och Express** för backend-delen.

**SQLite3** användes som lokal databas för att lagra och hantera projektets data. Backend-delen gjorde det möjligt för webbplatsen att kommunicera med databasen och hämta data som sedan användes i frontend.

Projektet gav mig därför en första praktisk förståelse för hur frontend, backend och databas kan samverka i en webbapplikation.

## Kom igång med projektet (Installation)
Följ dessa steg för att köra projektet lokalt på din dator:

1. **Klona repot:**
   ```bash
   git clone https://github.com/CJ-dev007/freaky-fashion
   ```
2. **Navigera till projektmappen:**
   ```bash
   cd freakyfashion
   ```
3. **Installera beroenden:**
   ```bash
   npm install
   ```
4. **Starta applikationen:**
   ```bash
   npm start
   ```
När servern har startat hittar du sidan live i din webbläsare på:  
**`http://localhost:3000`**
